# 📊 Attendance Dashboard

A responsive **Attendance Dashboard** built with HTML and modern CSS to practice layout design, structured sections, and user interface styling.

---

## ✨ Features

* 📊 **Attendance Overview** – High-level visual tracking components.
* 👤 **Student Information Section** – Organized student profile views.
* 📚 **Subject-Wise Tracking** – Detailed breakout sections per course.
* 📈 **Percentage Progress Indicators** – Clear layouts for tracking thresholds.
* 🗓️ **Structured Data Records** – Clean, readable data tables for history logs.
* 📱 **Responsive Dashboard Layout** – Adapts flawlessly across different screen sizes.
* 🎨 **Clean UI Design** – Balanced spacing, clear typography, and card-based design components.

---

## 🛠️ Technologies Used

* **HTML5** – Web page structure and semantic dashboard components
* **CSS3** – Modern layouts (Flexbox/Grid), custom cards, styled tables, and fluid responsiveness

## 🚀 How to Run

Get this project up and running locally by following these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kavivadhana/Attendance-Dashboard.git
   ```

2. **Navigate to the repository folder:**
   ```bash
   cd Attendance-Dashboard
   ```

3. **Launch the app:**
   Open the `sample.html` file in any modern web browser.

## 🎯 What I Learned

Building this layout helped me master several core styling principles:
* Constructing structured dashboard architectures using semantic HTML.
* Implementing clean interface blocks using modern **CSS Flexbox** and **Grid**.
* Styling advanced user interface elements including tables, metrics, and progress bars.
* Working with micro-interactions, responsive padding, typography scaling, and border stylings.
* Building mobile-first adaptations to keep elements structured on smaller breakpoints.
